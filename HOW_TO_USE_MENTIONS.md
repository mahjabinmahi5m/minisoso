# 📝 How to Use @Mentions - User Guide

## কীভাবে কাউকে Mention করবেন

### Posts এ Mention করা:

1. **New Post তৈরি করুন**
2. **@ টাইপ করুন**:
   ```
   "Hey @"
   ```
3. **User select করুন**:
   - একটা dropdown দেখাবে user list সহ
   - Username টাইপ করতে থাকুন filter করার জন্য
   - Click করে select করুন
4. **Post করুন**:
   ```
   "Hey @john, check this out!"
   ```
5. ✅ John notification পাবে!

---

### Comments এ Mention করা:

1. **কোনো post এ comment করুন**
2. **@ টাইপ করুন এবং username select করুন**
3. **Comment submit করুন**
4. ✅ Mentioned user notification পাবে!

---

## Examples:

### একজনকে Mention:
```
"Great photo @sarah!"
```

### একাধিক জনকে Mention:
```
"Meeting tomorrow with @john, @sarah, and @mike!"
```

### Post এ Mention:
```
"Just finished the project with @teamlead. Thanks for the help!"
```

### Comment এ Mention:
```
"@alice you should see this!"
```

---

## Mention Notification:

যখন কেউ আপনাকে mention করবে:

1. **Notification bell এ alert আসবে** 🔔
2. **Notification message দেখবেন**:
   - "@username mentioned you in a post"
   - অথবা "@username mentioned you in a comment"
3. **Click করলে সেই post/comment এ যাবেন**
4. **আপনার username blue color এ highlight থাকবে**

---

## Tips:

✅ **Do:**
- @ দিয়ে শুরু করুন
- Dropdown থেকে select করুন
- Multiple users mention করতে পারেন
- Posts এবং comments উভয়েই কাজ করে

❌ **Don't:**
- Space দিয়ে username লিখবেন না
- Special characters use করবেন না (শুধু letters, numbers, _, . allowed)
- নিজেকে mention করার দরকার নেই

---

## Features:

🔵 **Clickable Mentions**: @username click করলে profile এ যাবে
🔔 **Instant Notifications**: Mentioned user তৎক্ষণাৎ notification পাবে
🔍 **Smart Search**: Username বা name দিয়ে search করা যায়
👥 **Multiple Mentions**: একসাথে অনেককে mention করা যায়
