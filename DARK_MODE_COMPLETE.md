## 🎨 Color Palette:

### Dark Mode Colors:
```css

--bg-secondary: #121212    /* Card backgrounds */
--bg-tertiary: #1e1e1e     /* Input backgrounds */
--bg-hover: #2a2a2a        /* Hover states */
--border-color: #2f2f2f    /* Borders */
--text-primary: #ffffff    /* Main text */
--text-secondary: #b3b3b3  /* Secondary text */

--accent-blue-hover: #1877f2
--error-color: #ed4956     /* Red for errors/delete */
--success-color: #00ba7c   /* Green for success */
```
